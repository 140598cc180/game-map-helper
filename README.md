# 地图系列小助手（离线网页）

这是可直接放进 GitHub Pages 的静态网页目录，包含两套地图：

- 噩梦之女困难：最后更新 7.25，4 类、28 张地图。
- 磷光症噩梦：最后更新 11.8，6 类、15 张地图。

网页只读取同目录下的 `catalog.js` 和图片，不扫描文件夹、不调用接口、不依赖网络。打开 `index.html` 即可本地预览，也可以把本目录中的内容作为 GitHub 仓库根目录提交。

入口顺序是“系列 → 类别 → 地图缩略图 → 详细地图”。详细地图支持缩放、拖动、双击放大和移动端双指缩放。

如果以后补充或替换地图图片，需要同步更新 `catalog.js` 中对应的相对路径和地图记录，再提交整个目录。
